                    Setup
                    
  
                      
  
                      
    
                      

    
                      
      
                      Welcome
                      
      
                      This Echo Plus runs lidar: mainline Linux with its own services for the speaker, the LED ring, Wi-Fi, Bluetooth and the Zigbee and Thread radio, in place of Fire OS. lidar is an independent project and not affiliated with the maker of the device.
                      
      
                      A few steps get it ready:
                      
      
                        
        
                      • Login: a PIN or password for this web interface
                        • 
        
                      • Fire OS files: the Wi-Fi firmware and the speaker tuning lidar needs from your own Fire OS
                        • 
        
                      • Fire OS image: a full copy of the original system, for you to keep
                        • 
        
                      • Wi-Fi: the network the Echo joins
                        • 
        
                      • Device name: what phones see
                        • 
        
                      • Voice assistant: wake word, language and API key
                        • 
      
                      
      
                      Every step can be skipped and done later; the setup can be run again from System.
                      
    
                      

    
                      
      
                      Protect the web interface
                      –
                      
      
                      This web interface controls the whole Echo: music, volume, Wi-Fi, services, files. A PIN or password keeps everyone else in your network out. It is asked once per browser, and again after 30 days or a restart of the Echo.
                      
      
                      
      
                      
      
                      Nothing is encrypted on the way (no HTTPS): the PIN or password can be read by whoever can listen in on the network, so use the web interface in your own network only and never open it to the internet. Forgotten: restart the Echo and, once the ring lights up, hold both volume buttons until it flashes green three times (about 10 s).
                      
    
                      

    
                      
      
                      Fire OS files
                      –
                      
      
                      lidar cannot ship two things, as they may not be redistributed: the Wi-Fi firmware (Wi-Fi and Bluetooth both need it) and Amazon's tuning for this speaker. It takes them from the Fire OS on this Echo and keeps its own copy.
                      
      
                        
      
                        
      
                        
        
        
      
                        
      
                        A backup is the tar file of "Download backup" (lidar-fireos export). Keep one on your PC: an Echo without Fire OS and without this copy needs it. Restored files take effect after a reboot.
                        
    
                        

    
                        
      
                        Fire OS image
                        –
                        
      
                        The original system still sits untouched on the Echo (partition system_a). Download a complete copy and keep it in a safe place: once that partition is put to other use, this file is the only way back to the original system.
                        
      
                        No Fire OS was found on system_a: there is nothing to download.
                        
      
                        
        
                        The image is private: it holds software licensed for this one device and data specific to it. Never share or publish it.
                        
        
                        
          Download image
          
        
                        
        
        
                        The partition is only read, nothing on the Echo changes. The download is compressed, takes several minutes and shows no total size; wait until the browser reports it complete. "gzip -t" on the PC checks the file.
                        
      
                        
    
                        

    
                        
      
                        Wi-Fi
                        –
                        
      
                        –
                        
      
                        The Wi-Fi firmware is missing: Wi-Fi cannot start until the Fire OS files are restored and the Echo has rebooted.
                        
      
                        
        
        
      
                        
      
                        
        
        
        
                        
      
                        
      
                          
      
                          WPA2-Personal. The network is saved on the Echo and joined at every boot. Without Wi-Fi the Echo is reached over USB only, and the clock is not set.
                          
    
                          

    
                          
      
                          Device name
                          
      
                          The name phones show for the Echo as a Bluetooth speaker.
                          
      
      
                          Up to 48 bytes. A new name takes effect after a reboot.
                          
    
                          

    
                          
      
                          Voice assistant
                          
      
                          Say the wake word, ask, and Claude answers through the speaker. The assistant itself is not part of this image yet: these settings are stored for it.
                          
      
      
      
      
      
                          
        
        
      
                          
      
                          The key is stored on the Echo, readable by root only, and is never shown again: only whether one is set and its last four characters. Questions go from the Echo to the Anthropic API and are billed to the key's account. The test needs Wi-Fi and a set clock.
